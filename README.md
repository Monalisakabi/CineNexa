\# SmartTicket – Smart Movie Ticket Booking Platform



SmartTicket is an online movie ticket booking platform designed to simplify movie discovery, seat selection, and ticket booking.



\## Technologies Used



\- Frontend: Angular, HTML, CSS, TypeScript

\- Backend: Java, Spring Boot

\- Database: MySQL

\- AI Service: Python, FastAPI

\- Caching and Seat Locking: Redis

\- Event Communication: Apache Kafka

\- Payment Gateway: Razorpay



\## Main Features



\- User registration and login

\- Movie and show browsing

\- Interactive seat selection

\- Online ticket booking

\- Payment integration

\- QR-code-based electronic tickets

\- Booking history

\- AI-powered recommendations and demand prediction



\## Project Structure



\- `backend/` – Spring Boot application

\- `frontend/` – Frontend application

\- `Angular1st/` – Additional Angular project

\- `ai-service/` – Python AI services



\## Setup



Configure database and Razorpay credentials using environment variables before running the backend.



Do not upload passwords, API keys, or secret credentials to GitHub.
