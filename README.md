\## 🌟 About CineNexa



CineNexa is a full-stack smart movie ticket booking application designed to make movie reservations seamless and intelligent.



It integrates AI-driven recommendations, Redis-based seat locking, Kafka event communication, and QR-code-based ticket generation to improve the complete booking experience.



\## ✨ Key Features



\- 🎥 Browse movies and available shows.

\- 💺 Interactive seat selection and booking.

\- 🔒 Redis-based temporary seat locking.

\- 🤖 AI-powered movie recommendations.

\- 📊 Demand prediction using Python AI services.

\- ⚡ Apache Kafka-based asynchronous communication.

\- 💳 Online payment integration.

\- 🎟️ QR-code-based electronic tickets.

\- 🔐 JWT-based authentication.

\## 🚀 Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/Monalisakabi/CineNexa.git

cd CineNexa

```



\### 2. Configure the backend



Configure MySQL, Redis, Kafka, and required environment variables.



\### 3. Run the Spring Boot backend



Open the backend project and run:



```bash

mvn spring-boot:run

```



\### 4. Run the Angular frontend



```bash

npm install

ng serve

```



\### 5. Run the Python AI service



```bash

cd ai-service

pip install -r requirements.txt

python -m uvicorn main:app --reload

```



Refer to individual project configurations for the required ports and environment variables.
